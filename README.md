El presente proyecto consiste en el desarrollo de Meteo-Caracas, una plataforma modular programada en Python bajo el paradigma de Programación Orientada a Objetos (POO). Su propósito principal es la gestión, análisis y visualización de datos meteorológicos para el Área Metropolitana de Caracas. La aplicación integra el procesamiento de datasets locales en formato JSON con la API REST de Open-Meteo, permitiendo consultar variables en tiempo real (temperatura, humedad, viento y condiciones WMO), calcular indicadores estadísticos de sesión y generar análisis históricos comparativos mediante la renderización de gráficos dinámicos con Matplotlib.
